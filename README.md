# Chiikawa AI 额度桌宠 · v0.4.0

Windows 10/11 x64 本地个人原型：默认只显示透明角色，悬停在形象外显示额度卡；单击有本地文字气泡，双击打开设置。八个角色、三档大小、拖动、托盘和自定义本地角色图片保留。

## 使用

解压 `release/ChiikawaQuotaPet-0.4.0-Windows-x64-Personal.zip` 的完整目录，双击 `ChiikawaQuotaPet.exe`。不需要 Node / Python / Edge / Chrome，不只复制 exe。程序未签名，请按企业安全规范审查，不要关闭安全软件。

设置中的在线来源有三个：

| 来源 | 要求 | 展示口径 |
|---|---|---|
| 公司账户 · EPT | 本机已安装并登录 EPT，终端 `ept usage` 正常 | 个人总预算 / 总消耗 / 剩余及比例，包含沙箱费用 |
| 个人账户 · DeepSeek | 本人官方 API Key | 平台官方余额，按 CNY / USD 显示，不推测总额或百分比 |
| 第三方平台 · 通用 API | 平台提供 HTTPS GET JSON 余额接口，本人有访问权 | 按明确配置的字段、认证方式与单位显示余额或总额度 / 已用 |

**手动输入、离线文字识别及粘贴导入已删除。**旧 manual / import / sample 来源升级后迁移到 EPT 未知值，保留形象与尺寸，不把旧数字冒充实时额度。FinOps 浏览器读取仍已停用。

## 开机启动与气泡

- 开机自启动默认关闭；只在发行版设置中由你主动切换时修改 Windows 登录项。启动后显示桌宠，不弹终端或登录窗口。
- 系统状态回读；任务管理器禁用时明确提示。开发版与隔离测试中禁用这个开关，不写真实系统登录项。
- 注册绑定当前 exe 路径。移动目录后需关闭再开启；删除程序前建议先关闭，避免遗留无效启动项。登录项不带 API Key、EPT 凭据或用户数据参数。
- 单击角色约 0.3 秒后出现不同的本地角色台词，约 4 秒自动收起。拖动不说话，双击打开设置并取消气泡；「点击文字气泡」可关闭。
- 台词由应用本地生成，不调用语言模型，不消耗 AI 额度，不是角色官方台词。气泡是独立透明窗口，不覆盖形象或额度卡；屏幕空间不足时优先保留形象，必要时暂时收起额度卡。

## 第三方通用查询

选择第三方来源，填写你平台文档中的**余额 API 完整地址**，而不是 `/v1/chat/completions`。支持 Bearer Key、自定义 Key 请求头或无认证；所有请求固定 GET，不跟随重定向，不使用浏览器 Cookie。

- 通用 JSON：余额路径例如 `data.balance`；总额度 / 已用模式分别配置 `data.total` / `data.used`。
- DeepSeek 兼容预设：余额行 `balance_infos.0.total_balance`，核对响应币种。对真正的 DeepSeek 官方账户优先使用专用来源。
- New API 令牌字段模板预设：`data.total_granted` / `data.total_used`；默认显示原始 credit，核对平台是否提供相应令牌接口。**令牌额度不是账户余额，接口兼容性与单位不可只凭平台名称保证。**
- 只读点路径，支持数组索引，不执行脚本。换算为「原始数值 ÷ 除数」；默认除数 1，不假设积分等于人民币。
- 保存前必须确认域名、字段与单位。第三方 Key 与 DeepSeek Key 完全隔离；更改接口地址或认证目标清除第三方 Key 与缓存，须重新输入。
- 每次最多 10 秒、64 KiB 正文；响应无效、无权限、超时或来源变化时不覆盖旧值。没有余额 API 的平台暂不支持自动查询，不回退浏览器、离线输入或模型推理。

详见 [第三方接口说明](docs/custom-api.md)。本版只用模拟 API 验证通用功能，未使用真实第三方充值账号；请本人核对原站数字。

## EPT 查询

优先固定执行 `ept usage --summary-only --json`，本机已验证支持；旧 CLI 明确不支持参数时才回退 `ept usage`。EPT 自己管理认证，桌宠不读取或复制 token / config，不安装或附带 EPT。自定义路径只允许本机 ept.exe，禁止任意 shell 命令。

默认启动自动查询，其他已配置在线来源也会尝试启动查询；刷新间隔 1 / 5 / 15 / 30 分钟，可手动刷新。缓存或失败明确标非实时；从未查询显示 `—`，不是样例或零额度。显示时间是本地读取时间，不保证连续实时或服务端结算时效。

## 隐私、迁移与分享

发布版配置与缓存保存在 exe 同目录 `user-data/`，开发版为 `.local-data/`。选择记住的 Key 使用 Electron safeStorage 本机系统加密：DeepSeek 文件 `deepseek-key.bin`，第三方文件 `custom-api-key.bin`；不选择记住则仅在进程内存，退出重新输入。原文不传入窗口状态、不保存到 JSON / 日志 / 分享包。清除本地 Key 不代表平台撤销；跨电脑不承诺加密文件可解密。

**只分享打包脚本生成的干净 ZIP，不分享运行后的 user-data、旧浏览器 profile 或 EPT 凭据。**旧浏览器敏感目录不会读取或自动删除；清理需本人退出后确认路径，不误删 EPT 数据。另一台电脑使用自己安装登录的 EPT 或自己的平台 Key，登录状态不能随 ZIP 移植。

## 开发与验证

需要 Node.js 24 与 npm，`npm ci` 安装锁定开发依赖。运行 `npm start`；单测 `npm test`；桌面回归 `npm run test:desktop`；真实 EPT `npm run test:ept`；发行构建 `npm run build`；两种回归加 `-- --packaged` 验证发行版；分享包 `npm run package:share`，独立复核 `npm run package:share -- -VerifyOnly`。

Playwright 仅开发测试，没有生产 npm 依赖。当前验收、限制及 ZIP SHA256 见 [v0.4交付记录](docs/verification-v040.md)；v0.1–v0.3文档为历史，不代表当前入口。
