Chiikawa AI 额度桌宠 v0.4.0 · Windows 10/11 x64 个人原型

1. 解压 ChiikawaQuotaPet-0.4.0-Windows-x64-Personal.zip 完整目录，再双击 ChiikawaQuotaPet.exe。保留所有运行时文件，不只复制 exe，无需 Node、Python、Edge 或 Chrome。
2. 默认公司账户 EPT：本机需已安装并由本人登录 EPT，确认终端 ept usage 正常。桌宠不附 EPT、不复制凭据，优先 usage --summary-only --json，旧版明确不支持参数时才回退 usage。
3. 个人 DeepSeek：选择官方来源，在设置输入自己的 Key，可本机系统加密记住或仅本次使用。只查询官方余额，不发模型推理请求。
4. 其他第三方平台：选择通用 API，按平台文档填写 HTTPS GET JSON 余额接口、认证方式、余额字段路径或总额度 / 已用字段、币种及换算除数，并确认发送目标。另输入此平台自己的 Key，绝不复用 DeepSeek Key。
5. 通用预设包括通用 JSON、DeepSeek 兼容格式、New API 令牌字段模板。仅仅聊天接口兼容不能保证余额接口可用；没有对应余额 API 的平台暂不支持。New API 预设默认原始 credit、除数 1，不假定人民币换算；令牌额度不是账户余额。详见 custom-api.md。
6. 认证头支持 Bearer 或安全的自定义 Key 头（如 X-API-Key、api-key），不支持 Cookie、任意 POST、URL 密钥、查询参数或重定向。更换接口地址 / 认证目标清除此平台 Key 与旧缓存，需重新输入。
7. 在线启动 / 手动刷新与 1 / 5 / 15 / 30 分钟间隔；失败保留缓存并标非实时，首次未知显示“—”。时间是本地查询时间，不保证持续实时或供应商结算时效。
8. 手动金额输入、离线识别与粘贴导入已删除；旧 manual/import/sample 缓存迁移 EPT 未知，形象与尺寸保留。浏览器 FinOps 读取仍已停用。
9. 单击角色显示本地文字气泡（约 4 秒自动收起），八角色有不同台词，不消耗 AI 额度，不是官方台词。设置可关闭气泡；拖动不触发，双击打开设置。独立气泡不遮挡形象 / 额度卡；空间不足时暂时收起额度卡。
10. 默认只显示角色，悬停显示独立额度卡；也可常显，三档大小、八角色、自定义本地 PNG/GIF/WebP、置顶、减少动画保留。托盘可显示、刷新、设置及退出。
11. 开机自启动默认关闭；在发行版设置中自行开启 / 关闭，系统状态回读。任务管理器禁用时按提示处理。移动文件夹后关闭再开启，删除程序前建议关闭。开发版与隔离测试禁用开关，测试不改真实系统登录项。

隐私与换机：user-data 保存设置、额度缓存、自定义图片及可选加密 Key，整体目录并非全目录加密。DeepSeek Key 文件 deepseek-key.bin，第三方 custom-api-key.bin；原文不进状态 JSON、日志或分享包。清除本地 Key 不等于平台撤销，加密文件不保证跨机可解密。
不要分享运行后的整个目录、user-data、.local-data、旧浏览器 profile 或 EPT 凭据。另一台电脑使用自己的 EPT 安装登录或自己的平台 Key；无 EPT 可以选择其他在线平台，但不再提供手动额度。旧浏览器敏感目录不会读取或自动删除，须本人退出后确认路径清理，不误删 EPT 数据。

未代码签名、无自动更新、无遥测、不调用模型；企业终端按安全规范审查，不禁用安全软件。仅 Windows x64，不是 macOS/Linux/ARM 通用包。
第三方通用 API 和系统开关使用模拟测试验证；真实 EPT 另行实测。没有使用真实第三方充值账号，不把模拟数字称为当前余额。详细验证记录位于项目 docs/verification-v040.md。
